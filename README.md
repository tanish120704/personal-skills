# Personal Skills

Reusable personal skills for Codex and compatible agents.

## Engineering Judgment

Evaluate software engineering decisions using evidence, tradeoffs, complexity, uncertainty, delivery, operations, and ownership. Covers design, technical strategy, build-versus-buy, migrations, and production decisions.

The skill uses focused references rather than prescribing one architectural approach. It distinguishes source-backed claims from original decision aids and explains when a principle may not apply.

### Install

Copy `skills/engineering-judgment` into your Codex skills directory (normally `~/.codex/skills/engineering-judgment`). Review existing files before replacing an installed version.

### Use

> Use $engineering-judgment to evaluate this proposal. Explain the tradeoffs, assumptions, and what would change your recommendation.

Automatic selection is enabled in the skill metadata.
